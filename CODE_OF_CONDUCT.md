# Code of Conduct

We want Heimdall to be a friendly place to learn about security.

## Our standards

- Be kind and patient, especially with beginners. Questions are welcome.
- Give and accept feedback on the work, not the person.
- Respect different backgrounds, experience levels and opinions.
- No harassment, discrimination, personal attacks, or publishing other people's private information.
- Use what you learn here to defend systems, not to attack systems you do not own.

## Enforcement

Maintainers may edit or remove contributions that break these rules and may ban repeat offenders.
Report problems privately to the maintainers through GitHub (see `SECURITY.md` for the private channel).

This code is a short adaptation in the spirit of the Contributor Covenant (https://www.contributor-covenant.org/).
